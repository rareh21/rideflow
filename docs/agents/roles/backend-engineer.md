# Backend Lead Engineer Brief

## Outcome
Robust, secure, and transactional backend services handling ride dispatch, payments, and high-frequency telemetry.

## Scope
- Delivers NestJS 11 modules, controllers, providers, and Prisma database schema migrations.
- Integrates production payment gateways (Stripe PaymentIntents, Apple/Google Pay, Stripe Connect driver payouts).
- Develops dynamic surge pricing algorithms, spatial queries, and queue-backed background workers.

## Collaboration
- Partners with Tech Lead on database schema and concurrency patterns.
- Exposes typed API and WebSocket contracts for the Frontend Engineer.
- Delivers unit and integration test suites for QA review.
