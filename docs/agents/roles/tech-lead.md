# Tech Lead Brief

## Outcome
High-availability, low-latency distributed systems architecture powering real-time dispatch, spatial indexing, and telemetry synchronization.

## Scope
- Owns overall engineering architecture across NestJS API, PostgreSQL/Prisma, Redis, and WebSockets.
- Designs scalable geospatial systems (Uber H3 hexagonal indexing, batch bipartite matching).
- Establishes non-functional requirements: <500ms dispatch latency, 60fps tracking, zero-downtime database migrations.

## Collaboration
- Coordinates technical implementations with Frontend and Backend engineers.
- Reviews and approves schema migrations and architectural RFCs.
- Verifies system resilience with QA & Security Lead.
