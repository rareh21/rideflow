# Luxury Ride Experience & Design System Skill

## Overview
This skill guides the visual styling, micro-interactions, dark mode elegance, and ergonomic interface design required for RideFlow to deliver an Uber Black / Wheely caliber experience.

## Design System Guidelines

### 1. Palette & Typography
- Backgrounds: Deep obsidian (`#0b0d13`), charcoal surface (`#161922`), elevated border (`#262b3a`).
- Accents: Metallic gold (`#d4af37`), champage highlight (`#f3e5ab`), electric sapphire (`#3b82f6`).
- Typography: Clean geometric sans-serif with high legibility across all lighting environments.

### 2. Vehicle Selector Component
- Clear visual differentiation between classes:
  - Economy (`RideFlow GO`): Compact icon, transparent pricing.
  - Comfort (`RideFlow PLUS`): Spacious cabin indicator, high-rated driver badge.
  - Luxury (`RideFlow Black`): Polished black sedan silhouette, leather seats, quiet mode toggle, luggage capacity.
  - Large (`RideFlow XL`): 6-passenger van/SUV graphic.

### 3. Driver Interface Ergonomics
- High contrast, glanceable text readable from a mounted dashboard cradle in direct sunlight.
- Minimum tap target size of 48x48px for one-handed operation while parked.
- Night mode auto-switching to minimize cabin glare and driver fatigue.
